# Sistema Crypto Exchange

Este projeto é um **sistema de Crypto Exchange**, que permite aos usuários comprar criptomoedas de diferentes empresas de maneira prática.

---

## Funcionalidades
- Cadastro e login de usuários  
- Visualização de criptomoedas disponíveis e seus valores 
- Compra de criptomoedas de diferentes empresas  
- Gerenciamento de perfil 

---

## Tecnologias Utilizadas

### Front-end
- **HTML** – Estrutura das páginas  
- **CSS** – Estilização e layout responsivo  
- **JavaScript** – Interatividade e manipulação dinâmica de elementos  

### Back-end
- **PHP** – Lógica do servidor e integração com o banco de dados  
- **SQL** – Consultas e manipulação de dados  

### Banco de Dados
- **MySQL** – Armazenamento e gerenciamento de informações do sistema
